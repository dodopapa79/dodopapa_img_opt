# 네이버 블로그 이미지 최적화 & 썸네일 제작 스튜디오
(Naver Blog Image Optimizer & Thumbnail Studio)

서버 전송 없이 100% 브라우저(클라이언트 Canvas API)에서 동작하는 네이버 블로그 전용 이미지 최적화 및 썸네일 제작 웹 애플리케이션입니다.

---

## ✨ 주요 기능

### 1. 이미지 일괄 최적화 & 압축
- **네이버 최적 해상도**: 900px(권장), 1200px, 600px, 원본 유지
- **최신 WebP 변환**: 고화질을 유지하며 JPG 대비 최대 70~80% 용량 절감
- **다단계 점진 축소 (High-Quality Downscaling)**: 이미지 축소 시 글자나 얇은 선이 흐려지지 않는 선명한 화질 보존
- **정사각형 1:1 패딩 & 슬림 여백**: 규격 미달 이미지에 깔끔한 여백 처리
- **일괄 다운로드**: 변환된 이미지를 압축된 ZIP 파일로 한 번에 다운로드

### 2. 정밀 캔버스 이미지 에디터
- **비율별 자유 크롭**: 1:1, 4:3, 16:9, 자유 비율
- **화살표 & 강조 말풍선**: 자동 대비 글자색, 부드러운 곡률, 자유 회전 및 이동
- **텍스트 박스 & 번호 뱃지**: 폰트 크기, 외곽선, 그림자, 배경 배지
- **부분 모자이크 (블러)**: 개인정보나 민감 영역 즉시 비식별화
- **미리보기 완성 확인**: 편집 테두리와 앵커를 숨겨 최종 결과물 즉시 확인

### 3. 블로그 썸네일 제작기 (Thumbnail Maker)
- **3대 규격 지원**: 1:1 (정사각형), 16:9 (와이드), 4:3 (클래식)
- **배경 커스텀 & 로컬 보존**: 배경 이미지 업로드 시 브라우저에 영구 저장 (그라데이션 및 단색 배경 지원)
- **배경 어둡기(Dim) 조절**: 텍스트 가독성을 위한 오버레이 조절
- **자유 드래그 텍스트 레이어**: 마우스 드래그로 손쉬운 텍스트 배치 및 스타일링
- **원클릭 디자인 프리셋**: 감각적인 타이틀 템플릿 즉시 적용

## 🚀 로컬 실행 방법

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저에서 접속
# http://localhost:3000
```

## 📦 프로덕션 빌드 & GitHub Pages 배포

```bash
# 정적 파일 빌드
npm run build
```
빌드된 산출물은 `dist/` 폴더에 생성되며, GitHub Pages나 Vercel, Netlify, Cloud Run 등에 즉시 배포할 수 있습니다.
